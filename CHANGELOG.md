## [1.0.0] - 2026-10-12

### Added
- Initial 90-day curriculum covering Linux fundamentals, Computer Networking, Cloud computing fundamentals, AWS, Containers with Docker, Container Orchestration with Kubernetes, Infrastructure as Code with Terraform, CI/CD pipelines, Observability & Monitoring, and Cloud Security.
- 5 bonus days (Days 91–95) covering advanced cloud architectural topics.
- Comprehensive multi-tier capstone project integrating real-world infrastructure and deployment workflows.
- Hands-on labs with step-by-step technical instructions for each learning module.
- Practical cheatsheets for Linux, Docker, Kubernetes, AWS CLI, and Terraform.
- Cloud engineer interview questions and model answers spanning conceptual, technical, and behavioral topics.
- Comprehensive cloud engineering glossary defining essential industry terminology.
- GitHub Actions workflows for continuous integration, markdown linting, and automated link checking.
- GitHub issue templates and pull request templates to facilitate community contributions.
- Interactive progress tracker for learners to monitor and record their daily milestones.
