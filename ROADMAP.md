# 🗺️ Project Roadmap

Welcome to the project roadmap for **90 Days of Cloud Engineering**! This document outlines where the project stands today and our strategic vision for the future.

---

## 🔭 Vision

Our vision is to **become the best free cloud engineering learning path** in the world. We want to remove financial and technical barriers to entry in cloud computing by providing an entirely free, community-driven, production-ready curriculum that equips learners with real-world skills, hands-on lab experience, and the confidence to land their first cloud engineering role.

---

## 📍 Current Status: v1.0 - Initial Release

We have officially launched **v1.0 - Initial release**!
- Full 90-day core curriculum covering Linux, Networking, AWS Cloud, Containers (Docker), Kubernetes, Infrastructure as Code (Terraform), CI/CD, Observability, and Cloud Security.
- 5 bonus days (Days 91–95) covering advanced cloud topics.
- Comprehensive end-to-end capstone project.
- Complete set of hands-on labs, cheatsheets, interview question banks, and cloud engineering glossary.
- Automated CI testing workflows and issue templates for community contributors.

## 💡 How to Suggest Features

We welcome ideas and feature suggestions from the community! If you have a suggestion for a new topic, track, tool, or improvement:

1. Check existing [GitHub Issues](https://github.com/ahmadjawad533/90-days-of-cloud-engineering/issues) or discussions to see if the idea has already been suggested.
2. If not, open a new feature proposal using our [Topic Suggestion Template](.github/ISSUE_TEMPLATE/new-topic.yml) (or open an issue and select the topic suggestion template).
3. Outline your suggestion, explain how it benefits learners, and share any initial implementation ideas.
4. Join the discussion as maintainers and fellow learners collaborate on planning and implementing the feature!
