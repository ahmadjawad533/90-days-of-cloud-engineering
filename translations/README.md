# Translations

Translations of the **90 Days of Cloud Engineering** content are warmly welcomed! Helping make cloud engineering education accessible in different languages empowers learners worldwide.

## How to Contribute a Translation

1. **Open an Issue First**:
   - Before starting a translation, please open an issue using the [Topic / Feature / Question] template to coordinate with maintainers and ensure no one else is currently working on the same language.

2. **Create a Language Directory**:
   - Create a new directory under `translations/` named after your target language's IETF language tag / code (for example: `es/` for Spanish, `pt-br/` for Brazilian Portuguese, `hi/` for Hindi).

3. **Mirror the Directory Structure**:
   - Maintain the exact directory structure of the repository inside your language folder (e.g., `translations/es/days/day-01/README.md`).
   - Translate the day README files, explanations, and instructions.

4. **Link Back to the English Original**:
   - At the top of every translated document, include a reference link back to the original English version:
     ```markdown
     > English version: [Day XX](../../../days/day-XX/README.md)
     ```

5. **Submit a Pull Request**:
   - Once your translation (or a subset of days) is ready, submit a Pull Request following our pull request template and guidelines.
